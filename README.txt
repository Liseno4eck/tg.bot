# Telegram бот

## Что делает бот

- `/start` → отвечает `я работаю`
- сохраняет чаты, где был использован `/start`, в `chats.json`
- после запуска отправляет владельцу сообщение `бот успешно подключен`
- после перезапуска загружает ранее сохранённые чаты из `chats.json`

## Установка

```bash
pip install -r requirements.txt
```

Создай файл `.env` на основе `.env.example`:

```text
BOT_TOKEN=токен_бота
OWNER_ID=твой_Telegram_ID
```

Запуск:

```bash
python bot.py
```

Единственная команда бота:

```text
/start
```

Других команд в коде нет.

Важно: это обычный Telegram Bot API-бот. Он не отправляет сообщения от имени личного аккаунта. Для Telegram Business → «Автоматизация чатов» нужна отдельная реализация.
